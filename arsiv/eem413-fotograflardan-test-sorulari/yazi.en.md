Anonymous notes in the course archive were transcribed to text from photographed pages. The photographs are kept in the private archive; there is no download file in this post. Where a document carries no date, the date record of the source file was used.

## First test: questions and options

The numbering in the photographs has been preserved. Questions that were left blank or fell outside the frame were not completed; there is no answer key.

**1.** Which of the following is NOT a benefit provided by computer networks? A) Sharing resources; B) Sharing information; C) Creating layers; D) Standardization in software.

**2.** Which network belongs to an organization and can be accessed only by that organization's employees? A) MAN; B) Ethernet; C) Intranet; D) WAN.

**3.** Which layer performs data compression/decompression and encryption/decryption? A) Application; B) Presentation; C) Transport; D) Data transmission.

**4.** Which layer is associated with EBCDIC–ASCII conversion and the PICT, TIFF, JPEG, MIDI, MPEG, and HTML formats? A) Application; B) Presentation; C) Transport; D) Data transmission.

**5.** Which layer decides on retransmission in case of errors and organizes and synchronizes communication? A) Application; B) Presentation; C) Transport; D) Session.

**6.** Which type of communication is it when one computer sends data first and then the other does? A) Half duplex; B) Full duplex; C) Simplex; D) Two-way.

**7.** At which layer do TCP and UDP operate? A) Application; B) Presentation; C) Transport; D) Session.

**8.** At which layer does IP operate? A) Application; B) Network; C) Transport; D) Session.

**9.** Which general structure determines the placement of computers, their connections, and the structure of data transmission? A) Topology; B) OSI model; C) Layers; D) LAN.

**10.** In which topology does a circulating token exist? A) Ring; B) Star; C) Linear; D) Tree.

**11.** In which topology does the entire connection go down when one computer fails? A) Ring; B) Star; C) Linear; D) Tree.

**12.** In which topology are the others unaffected when the cable connected to one computer fails? A) Ring; B) Star; C) Linear; D) Tree.

**13.** Which topology is the one in which many nodes are connected to each other with multiple links? A) Ring; B) Star; C) Mesh; D) Tree.

**14.** Which device connects the same or different topologies? A) Hub; B) Switch; C) Bridge; D) Repeater.

**15.** The question text is missing in the source.

**16.** Which device strengthens the signal by placing an amplifier in between? A) Hub; B) Switch; C) Bridge; D) Repeater.

**17.** The question is outside the frame; only the options Router, Switch, Bridge, Repeater are visible.

**18.** Which device combines a router and a bridge in one device? A) Brouter; B) Router; C) Bridge; D) Repeater.

**19.** Which number is defined on an Ethernet card? A) IP; B) TCP; C) MAC; D) UDP.

**20.** Which protocol is used to connect to a multi-user machine from another remote machine? A) FTP; B) Telnet; C) HTTP; D) DNS.

**21.** Which protocol is used to receive e-mail? A) POP3; B) SMTP; C) HTTP; D) Telnet.

**22.** Which protocol does not track the packet and does not guarantee that it reaches its destination? A) TCP; B) IP; C) UDP; D) HTTP.

**23.** What is the broadcast address of the network containing the address 129.50.120.2? A) 255.255.0.0; B) 129.50.255.255; C) 129.50.0.0; D) 129.50.120.0.

**24.** What is the network address of the network containing the address 124.50.120.2? A) 124.0.0.0; B) 255.255.0.0; C) 124.50.0.0; D) 124.50.255.255.

**25.** What is the broadcast address of the network containing the address 203.23.123.2? A) 203.255.255.255; B) 203.0.0.0; C) 203.23.255.255; D) 203.23.123.0.

**26.** What is the property of the address 127.0.0.0? A) The machine talking to itself (loopback); B) Reserved for LAN; C) Reserved for WAN; D) Reserved for MAN.

**27.** The question asks for the network mask of an IP address; since part of the address and options are blurry, it could not be resolved reliably.

**28.** Which command sends a 32-byte ICMP packet and reports the result? A) Ipconfig; B) Ping; C) Tracert; D) Netstat.

**29.** Which protocol is used to convert an IP address to a physical address? A) Ipconfig; B) Ping; C) Tracert; D) ARP.

**30.** The network 205.0.0.0 has been divided into two subnets: which of the following is the IP address of one of the subnets? A) 205.0.0.0; B) 205.0.205.205; C) 205.0.0.255; D) 205.0.0.205.

**31.** In the same case, which of the following is the broadcast address of one of the subnets? A) 205.0.0.0; B) 205.0.205.205; C) 205.0.0.255; D) 205.0.0.205.

**32.** In the same case, which of the following is the address of the network mask? A) 205.0.0.0; B) 205.0.205.205; C) 205.0.0.255; D) 205.0.0.128.

**33.** Which of the following applies to the CSMA/CD access method? A) It may slow down in large networks; B) To avoid collisions, data is sent at random intervals; C) Data is sent only when the line is idle; D) Data is lost when a collision occurs.

**34.** How is transmission controlled in the CSMA/CA access method? A) Before sending, it signals that it will send data; B) It sends at the first opportunity it finds the line idle; C) It sends according to a certain order; D) The priority computer sends first.

**35.** What is the cause of most network errors? A) Repeater; B) Network card; C) Misconfiguring local computers; D) Cable.

**36.** When choosing a cable, one should choose a cable with as high a transmission rate as possible. A) True; B) False.

**37.** A computer at a workplace cannot connect to the network; what is the first method to solve the problem? The following options are in the next photograph: A) Checking the cable; B) Removing the network card and connecting it to another network [line cannot be fully read]; C) Checking the cables and connections; D) Connecting to another computer that uses the same network card.

**38.** Data leaves the computer, but the other side cannot receive it: A) Break found in cable test [blurry]; B) Modem; C) Network card; D) Data bus.

**39.** The computer is on and the cable is disconnected; what happens when a text is sent? A) The sent data is corrupted; B) It can output to the cable and is corrupted; C) Only data from a high-priority job is sent; D) It delivers the information to the destination as empty. Some options are of low clarity in the photograph.

**40–41.** The CSMA/CD and CSMA/CA questions repeat questions 33–34.

**42.** What is done when two data transmissions collide in CSMA/CD? A) They are resent immediately; B) It waits for the other computer; C) Both wait for a certain period and resend; D) Both wait for a random period and resend.

**43.** Sending a large amount of data slows down the network; what is the solution? A) The data is divided into small packets; B) Each transmission is given a priority order; C) It waits to resend after a fixed amount; D) High-speed throughput cables are used.

**44.** Who examines the destination address in an Ethernet packet? A) Only the destination computer; B) The network cards of all computers; C) The CPU of each computer; D) The network server.

**45.** How is the token ring architecture described? A) Ring; B) Star; C) Logical star, physical ring; D) Logical ring, physical star.

**46.** How is an external modem connected to the computer? A) RJ-11; B) RJ-45; C) T connector; D) RS-232 serial cable.

**47.** Which is an advantage of a repeater? A) It filters data between segments; B) It joins Ethernet and Token Ring; C) It is inexpensive. The remainder is not visible in the photograph.

**27.** At which layer of the OSI model does a bridge operate? A) Network; B) Physical; C) LLC sublayer; D) MAC sublayer.

**28.** What is the best method for joining segments that use different protocols and architectures? A) Bridge; B) Gateway; C) Router; D) Repeater.

**29.** A gateway is used to connect segments with different operating systems. A) True; B) False.

**30.** A repeater can join networks with different access methods. A) True; B) False.

**31.** How does a bridge treat a packet whose destination address is not in its table? A) It does not forward it; B) It sends a request to all segments and finds the destination; C) It forwards it to segments other than its own segment; D) It sends it to the router, and the router determines the route.

**33.** At which layer is data divided into packets? A) Session; B) Application; C) Transport; D) Network.

*Note: The questions are based on legacy classful IPv4 addressing and a shared Ethernet approach; without a network mask given, address questions are in general not unambiguous. In question 25, the expected option 203.23.123.255 under a /24 assumption is not among the choices. The options in question 32 are not in the form of a subnet mask. In question 5, retransmission and session functions are confused. Blurry areas and missing options were not guessed.
