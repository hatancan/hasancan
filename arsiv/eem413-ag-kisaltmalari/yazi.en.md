The anonymous handwritten acronym sheet from the course folder has been transcribed into text. The source image is kept in a private archive; there is no download file. The date is the last-modified record of the source file.

## Acronym list

| Acronym | Expansion as written in the handwriting |
|---|---|
| RFC | Request for Comments |
| IETF | Internet Engineering Task Force |
| DSL | Digital Subscriber Line |
| DSLAM | Digital Subscriber Line Access Multiplexer |
| HFC | Hybrid Fiber Coax |
| FDM | Frequency Division Multiplexing |
| FTTH | Fiber to the Home |
| OLT | Optical Line Terminator |
| ONT | Optical Network Terminator |
| EVDO | Evolution–Data Optimized |
| HSPA | High Speed Downlink Packet Access [in the source] |
| WiMAX | Worldwide Interoperability for Microwave Access |
| TDM | Time Division Multiplexer [in the source] |
| ISO | International Organization for Standardization |
| OSI | Open System Interconnection [in the source] |
| SMTP | Simple Mail Transfer Protocol |
| RTP | Real-time Transfer Protocol [in the source] |
| HTTP | Hypertext Transfer Protocol |
| SIP | Session Initiation Protocol |
| FTP | File Transfer Protocol |
| TCP | Transmission Control Protocol |
| UDP | User Datagram Protocol |
| JPEG | Joint Photographic Expert Group [in the source] |
| URL | Unisource Resource Locator [in the source] |
| POP | Post Office Protocol |
| IMAP | Internet Mail Access Protocol [in the source] |

*Note: Some expansions in the source are incorrect: HSPA = High Speed Packet Access; the one containing "Downlink" is HSDPA. TDM = Time Division Multiplexing; OSI = Open Systems Interconnection; RTP = Real-time Transport Protocol; JPEG = Joint Photographic Experts Group; URL = Uniform Resource Locator; IMAP = Internet Message Access Protocol. The list preserves the source wording, and the corrections are noted here.*
