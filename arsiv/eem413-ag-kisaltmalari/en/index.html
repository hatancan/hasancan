EEM413 Computer Networks: Network Acronyms from Handwriting

EEM413 – Bilgisayar Ağları · 02.11.2015 · 18.10.2026

The anonymous handwritten acronym sheet from the course folder has been transcribed into text. The source image is kept in a private archive; there is no download file. The date is the last-modified record of the source file.

Note: Some expansions in the source are incorrect: HSPA = High Speed Packet Access; the one containing "Downlink" is HSDPA. TDM = Time Division Multiplexing; OSI = Open Systems Interconnection; RTP = Real-time Transport Protocol; JPEG = Joint Photographic Experts Group; URL = Uniform Resource Locator; IMAP = Internet Message Access Protocol. The list preserves the source wording, and the corrections are noted here.
