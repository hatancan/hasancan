## Matrix exponential and flows: 1–8

1. For a linear operator A on Rⁿ, show det(I + εA) = 1 + ε tr A + O(ε²) as ε → 0.
2. Show eᴬ = lim_(n→∞)(I + A/n)ⁿ.
3. Show det(eᴬ) = e^(tr A).
4. Show that the flow ẋ = Ax multiplies volume by e^(t tr A).
5. Show that the Hamiltonian vector field ẋ = Hᵧ, ẏ = −Hₓ on Rⁿ × Rⁿ generates a volume preserving flow.
6. If AB = BA, show Aeᴮ = eᴮA. Also show ‖eᵗᴬ‖ ≤ e^(|t|‖A‖).
7. Show that the eigenvalues of eᴬ are e^λᵢ, where λᵢ are the eigenvalues of A.
8. In a sufficiently small neighborhood of a nonsingular point, show ẋ = Ax is equivalent to ẏ₁ = … = ẏₙ₋₁ = 0, ẏₙ = 1.

## Phase portraits and coordinate changes: 9–14

**9.** Sketch the phase portrait of ẋ₁ = −x₂ + x₁(x₁² + x₂²), ẋ₂ = x₁ + x₂(x₁² + x₂²). Hint: use polar coordinates.

**10.** Show that y₁ = x₁ + x₂³, y₂ = x₂ + x₂² meets the flow box theorem requirements for ẋ₁ = −3x₂²/(1 + 2x₂), ẋ₂ = 1/(1 + 2x₂), near any point with x₂ ≠ −1/2. Find the trajectories.

**11.** Find the flows using Lie series and by solving differential equations:

- ẋ₁ = x₁, ẋ₂ = x₁ − x₂².
- ẋ₁ = x₁x₂, ẋ₂ = x₂².

**12.** Make ẋ = ξ(x,t), x(0) = x₀ autonomous by adding τ̇ = 1, τ(0) = 0. Apply to ẋ = tx², x(0) = x₀.

**13.** Convert y″ − y + 2y³ = 0, y(0) = 1, y′(0) = 0 to a system in R² and find its flow using Lie series.

**14.** Show that a fixed point of the flow generated by a vector field v is exactly a singular point of v.

## Nonautonomous systems and first integrals: 15–19

**15.** Solve ẋ = A(t)x + b(t), t > 0, for x(2) = (1,4)ᵀ, where A(t) = [[0,1], [−2/t²,2/t]] and b(t) = (t⁴,t³)ᵀ.

**16.** Show that I:Rⁿ → R is invariant under a flow if and only if its Lie derivative along the generating vector field vanishes.

**17.** For ẋ = ax − by, ẏ = bx + ay, the sheet asks to show that I = (x² + y²)exp[−(2b/a)arctan(y/x)] is a first integral, then use its level curves to sketch the phase portrait.

*Note: In polar coordinates ṙ = ar and θ̇ = b, so the logarithmic derivative of the given expression is 2a − 2b²/a, which is not zero in general. For b ≠ 0, a local first integral has the form r²exp[−(2a/b)θ]. The source has the ratio of a and b written the wrong way round.*

**18.** If a linear operator A leaves a subspace E invariant, show that eᴬ also leaves E invariant.

**19.** For ẋ = f(x/t,y/t), ẏ = g(x/t,y/t), show there is a first integral of the form I = F(x/t,y/t). Determine a necessary and sufficient condition for trajectories to lie on spheres centered at the origin.

## Classification and initial value problems: 20–23

**20.** Classify the origin as a saddle, node, focus or center for ẋ = Ax, and determine stability of nodes or foci:

| Part | A |
|---|---|
| a | [[1,2], [3,4]] |
| b | [[1,−1], [2,3]] |
| c | [[3,1], [1,3]] |
| d | [[λ,2], [1,λ]] |

**21.** Solve ẋ = Ax, x(0) = x₀ for A = [[0,−2,0], [1,2,0], [0,0,−2]].

**22.** Solve the same initial value problem for A = [[1,−1], [1,3]] and A = [[1,1], [0,−1]].

**23.** Solve it for A = [[2,1,1], [0,2,2], [0,0,2]] and A = [[1,0,0], [−1,2,0], [1,0,2]].

## Jordan canonical form: 24–25

**24.** Find Jordan forms of [[1,1], [0,−1]], [[1,1], [−1,1]], and [[0,−1], [1,0]].

**25.** Find Jordan forms of [[1,1,0], [0,1,0], [0,0,1]] and [[1,0,0], [0,1,1], [0,0,−1]].

## Check during transcription

The sheet has no answer key. The eigenvalues of the first three matrices in question 20 were found to be (5 ± √33)/2, 2 ± i and 2 and 4, respectively: saddle, unstable focus, unstable node. The eigenvalues of the last matrix are λ ± √2; at the boundary values λ = ±√2 there is a zero eigenvalue, so those cases need separate treatment.
