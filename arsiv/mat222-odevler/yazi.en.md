## Assignment 1: find the general solutions

1. x(x² − a) + (y² − b)yy′ = 0.
2. e^(x/y)(y − x) dy + y(1 + e^(x/y)) dx = 0.
3. (y + x) dx + (y − x) dy = 0.
4. y′ = (x + y + 4)/(x − y − 6).
5. y′ = sin²(x − y + 1).
6. (x² + y²) dx − 2xy dy = 0.
7. (1 + y²) dx = (√(1 + y²) cos y − xy) dy.
8. y′ − 2xy/(1 + x²) = arctan x.
9. xy′ − 2y = x sin(1/x).
10. xyy′ + y² = x sinh x.

## Assignment 1: integrating factor questions

1. Show that if the equation P(x,y) dx + Q(x,y) dy = 0 is exact and homogeneous of degree n ≠ −1, its general solution can be written in the form xP + yQ = C.
2. Show that if P(x,y) dx + Q(x,y) dy = 0 is a homogeneous equation of degree n, it has an integrating factor of the form µ(x,y) = 1/(xP + yQ).

In these statements, the region where the factor is defined must be used; division is not possible at points where xP + yQ = 0.

## Assignment 2: higher-order equations

Find the general solutions of the following equations.

1. y″ + 4y′ + 5y = e⁻²ˣ(1 + cos x).
2. y⁽⁴⁾ − 16y = x² sin 2x + x⁴e²ˣ.
3. y⁽⁴⁾ + 10y″ + 9y = sin x sin 2x.
4. y⁽⁴⁾ + 2y″ + y = x² cos x.
5. y″ − 2 sin(α)y′ + y = 2 cos(α) sin x, α ≠ nπ/2.
6. y‴ − (2a + b)y″ + (a² + 2b)y′ − a²by = eᵃˣ.
7. y″ + 6y′ + 9y = e⁻³ˣ/√(x² + 1).
8. y‴ + 3y″ + 3y′ + y = e⁻ˣ/x³.
9. y‴ + y′ = sec x.
10. x²y″ − y = x/(x + 1).
11. x²y″ − (2a − 1)xy′ + (a² + 1)y = xᵃ ln x cos(ln x).
12. x³y‴ − 5x²y″ + 12xy′ − 12y = 3x² + x.

## Assignment 2: from a known solution to the general solution

A particular solution is given; find the general solution.

1. xy″ + 2y′ + xy = 0; y₁ = sin x/x.
2. x²y″ + xy′ + (x² − 1/4)y = 0; y₁ = sin x/√x.

The two given functions y₁ were checked by substitution on the intervals where they are defined. The handouts do not include an answer key.
