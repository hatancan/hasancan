MAT222 Differential Equations: 2002–2003 Midterms and Final (Başkent University)

MAT222 – Diferansiyel Denklemler · 14.01.2003 · 17.10.2026

This post brings together the two midterm exams and the final exam of the Başkent University Faculty of Engineering MAT222 Differential Equations course for the 2002–2003 term. The questions and equations were transcribed from page images into text; the documents contain no answer key. The three PDFs, converted from Word documents, can be downloaded as a single ZIP at the end of the post.

The second page of the first two exams contains only the text "Good luck!". The second page of the final contains the continuation of the questions. The date of the archive record is 14 January 2003, the date of the last exam in the group.

First midterm — 19 November 2002

Question 1 — 4 points

Find all solutions of the differential equation:

x² dy/dx + xy = y³/x

Question 2 — 4 points

Solve the initial value problem:

x dy/dx − y = x tan(y/x), y(1) = π/6

Question 3 — 3.5 points

Find the solution of the initial value problem in explicit function form:

xy dx + (x + 1) dy = 0, y(0) = e

Question 4 — 4 points

Find all solutions of the differential equation:

(y − x) dx + x(2y² − xy + 1) dy = 0

Question 5 — 4.5 points

Find all solutions of the differential equation in explicit function form:

y = x + 2y′ − ln((y′)²)

Note: The notation y′² in the source means (y′)².

Second midterm — 24 December 2002

Question 1 — 4 points

Are the following functions linearly dependent? Prove your answer.

  • a) x⁴, x²e^(2x), e^(4x)
  • b) 2^(4x+1), 3^(3x+2), 4^(2x+3), 5^(x+4)

Question 2 — 5 points

Solve the initial value problem. Check the correctness of your solution.

y‴ + 7y″ + 8y′ − 16y = 0

y(0) = −1, y′(0) = 1, y″(0) = −17

Question 3 — 5 points

Can the following function be a solution of a homogeneous linear differential equation with real constant coefficients (HLDECC)? If your answer is "yes", write such an HLDECC of the lowest possible order using the differential operator:

y = 4x sin(x)e^(−2x) + (3x² − 5)e^(2x) + 7 − 2sin²(x)

Question 4 — 6 points

Find the general solution of the following equation using the method of undetermined coefficients:

y″ − 2y′ + 2y = 2sin(x)e^x

Final exam — 14 January 2003

Question 1 — 5 points

Find all solutions of the differential equation in explicit function form:

y |ln y − ln x| dx − x dy = 0

Question 2 — 5 points

Find the general solution of the differential equation:

(1 + y² sin(2x)) dx − 2y cos²(x) dy = 0

Question 3 — 6 points

Find the general solution of the differential equation:

y″ + 2y′ + y = 15e^(−x)√(x + 1)

Question 4 — 6 points

Solve the differential equation using power series about the point x₀ = 0:

(2x² + 1)y″ − 4y = 0

Question 5 — 6 points

Solve the system of differential equations. Write the solution in explicit form.

  • dy/dt = 4y − z
  • dz/dt = 5y + 2z

Question 6 — 7 points

Answer the following questions with proofs.

6.1. Find the product of the differential operators:

(D + x)(D − x)

6.2. Does the existence and uniqueness theorem for solutions hold for the following initial value problem?

(x − 2)y′ = √y − x, y(0) = 1

6.3. Determine the types of the equations from the options below:

  1. (2y cos x + sin⁴ x) dx = sin x dy
  2. y′ = 2((y + 2)/(x + y − 1))²
  3. dy − 10^(x−y) dx = 0
  4. y′ = (x/y)e^(2x) + y

Options:

  • a) Bernoulli equation
  • b) Homogeneous equation
  • c) Linear equation
  • d) Separable equation
  • e) Equation reducible to a homogeneous equation

6.4. Show the form of a particular solution of the following linear differential equation using undetermined coefficients. There is no need to solve the equation or to find the undetermined coefficients.

y‴ − 4y″ + 3y′ = x² + xe^(2x)

6.5. Are the vector functions X(t) = (t, t)ᵀ and Y(t) = (t², t²)ᵀ linearly dependent on the interval (0, 1)?
