Content forms and past homework assignments for the Başkent University **EEM322 Control Systems** course, prepared by **Prof. Dr. Alper Uraz** for the 2005, 2007, 2008, 2011, and 2012 spring terms, are collected in this post. PDF copies of the documents can be downloaded as a ZIP at the end of the post. Student names that had been added to the homework schedule have been removed. The 2009 form can be found in the [existing syllabus post](/arsiv/eem322-izlence/).

## Textbooks

The main source in all forms is **A. Uraz, Control Systems, Hacettepe University, 2003**. Supplementary sources:

- K. Ogata, Modern Control Engineering: 4th edition (2002) in the older forms, 5th edition (2010) in the 2011–2012 forms.
- K. Ogata, Solving Control Engineering Problems with MATLAB, 1994: in the 2007 and later forms.
- R. C. Dorf and R. H. Bishop, Modern Control Systems: 10th edition (2005) in the older forms, 12th edition (2011) in the 2011–2012 forms.

## Common weekly plan

| Week | Topic |
|---|---|
| 1 | Introduction; electrical and mechanical system components |
| 2 | Fluid and thermal systems; servomotors |
| 3 | Block diagrams; signal flow graphs |
| 4 | State space description, state equations, state transition matrix, eigenvalues and eigenvectors |
| 5 | Transfer function decomposition; controllability and observability |
| 6 | Time response analysis; transient response |
| 7 | Steady-state error analysis |
| 8 | Midterm |
| 9 | Control system analysis; sensitivity, disturbance rejection, stability |
| 10 | Root locus plotting |
| 11 | Frequency response analysis; Bode, polar and gain-phase plots |
| 12 | Nyquist stability analysis |
| 13 | Relative stability; gain/phase margins; Nichols chart |
| 14 | Review |

In the 2011 and 2012 forms, the midterm and the stability/sensitivity weeks are written separately as "8/9".

## Versions of the other homework schedules

The later schedules use Chapters 5, 6, and 8 of Ogata together with Chapters 5 and 6 of Uraz. The distribution has two 62-set versions and a 45-set "EEM322-1 HW" version; the common problem assignments are in [the table in the 2009 syllabus post](/arsiv/eem322-izlence/).

- Submission for Chapter B-5 and B-6: Friday of week 11.
- Submission for Chapter B-8: Friday of week 14.
- Time responses, root locus, Bode, and Nyquist plots are prepared by hand.
- In the versions with a separate MATLAB project guideline, code and plots are required for the appropriate steps of the B-6, B-6/Uraz, and B-8/Uraz solutions; the project is due on the Friday of week 14.
- The other 62-set version requires all of these hand-drawn plots to be produced with MATLAB as well, in a single item.

In the download package, these versions are preserved under different names; PDF equivalents have been used instead of the original Office copies that contained personal information.
