This post contains three final exams dated **June 11, 1999, August 25, 2000, and August 6, 2001**. The emblem on the 2001 exam reads **Istanbul Technical University**. The other two documents carry "Mathematics Engineering" or MAT201; since the institution name is not stated explicitly, the same affiliation could not be confirmed for them. The preparer's name is not given. The three original PDFs, which have no answer key, can be downloaded as a ZIP at the end of the post.

## June 11, 1999

1. Solve the equation [x − 2y/ln(x² + y²)]y′ = y + 2x/ln(x² + y²). Find the orthogonal trajectories of the family of parabolas y² = 4c(x + c).
2. Construct the second-order linear homogeneous equation that has {xᵐ, xⁿ} as a fundamental solution set and determine its singular points. Also solve the equation y″ + 4y′ + y = e⁻²ˣ/(1 + x²).
3. For the equation (1 − cos x)y″ − sin(x)y′ + y = 0, find the regular singular points, the indicial equation and its exponents; write the Frobenius solution and the structure of the second solution.
4. Solve the equation x(1 − x)y″ + [p − (p + 2)x]y′ − py = 0 using hypergeometric functions. Can it be written in terms of elementary functions? Examine the case p = 1.
5. For X′ = AX + f, A = [[0, −1, −1], [−1, 0, −1], [−1, −1, 0]], f = (e²ˣ, eˣ, 0)ᵀ is given. Find the general solution.
6. L{J₀(t)} = (1 + s²)⁻¹ᐟ² is given. Compute L{eᵇᵗJ₀(at)} and ∫₀^∞ te⁻³ᵗJ₀(4t) dt. Solve the integral equation ∫₀ᵗ F(τ)F(t − τ)dτ = sin t. Solve the problem tY″ + (1 + 2t)Y′ + (5t + 1)Y = 0, Y(0) = 1, Y′(0) = −1 using the Laplace method.

## August 25, 2000: MAT201

1. For (2x + 1)y′ − 4e⁻ʸ + 2 = 0, find an integrating factor and obtain the general solution.
2. Solve the equation y⁽⁴⁾ − y = xeˣ + cos x.
3. For the equation x²y″ + (x² + 4x)y′ + 2(x + 1)y = 0, find a Frobenius solution about x = 0 and write it in elementary form. Obtain the second independent solution by reduction of order.
4. Solve the problem y″ + 4y = f(t), y(0) = 0, y′(0) = 1 using the Laplace method. f(t) = 1 for 0 < t < 1; f(t) = 0 for t > 1.
5. Solve the system X′ = [[2, −1], [3, −2]]X + (eᵗ, t)ᵀ.

## August 6, 2001: Istanbul Technical University MAT201

1. Solve the equation y dx + (x − yx³) dy = 0 using an integrating factor µ(xy) and as a Bernoulli equation. Compare the results.
2. Solve the equation 4y⁽⁴⁾ + y = sin(x/2) + xe^(−x/2).
3. For the equation xy″ − (x + 3)y′ + y = 0, find a series solution about x = 0; use reduction of order for the other solution.
4. Solve the problem y‴(t) − y′(t) = f(t), y(0) = 1, y′(0) = −1, y″(0) = 0 using the Laplace method. The source states f(t) = eᵗ for t ≥ 2 and f(t) = 0 for t > 2.
5. Solve the problem y″ + 2y′ + 5y = e⁻ᵗ sin 2t, y(0) = 3, y′(0) = −1.
6. Find the general solution of the system x₁′ = −x₂ + tan²t − 1, x₂′ = x₁ + tan t.

The fourth and fifth questions are optional; students are asked to answer a total of five questions.

*Note: In question 4 of the 2001 exam, the conditions t ≥ 2 and t > 2 overlap; the region t < 2 is left undefined. The piecewise function is printed this way in the source. Since the intended interval could not be verified, it was not corrected by choosing an interval.*
