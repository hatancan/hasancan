MAT222 Diferansiyel Denklemler: 1999–2001 Final Soruları (İTÜ ve kurum belirtilmeyen belgeler)

MAT222 – Diferansiyel Denklemler · 06.08.2001 · 17.10.2026

Bu yazı, 11 Haziran 1999, 25 Ağustos 2000 ve 6 Ağustos 2001 tarihli üç final sınavını içeriyor. 2001 sınavının ambleminde İstanbul Teknik Üniversitesi yazıyor. Diğer iki belgede “Matematik Mühendisliği” veya MAT201 var; kurum adı açık olmadığından onlar için aynı aidiyet kesinleştirilemedi. Hazırlayan adı bulunmuyor. Çözüm anahtarı olmayan üç orijinal PDF yazının sonunda ZIP olarak indirilebilir.

Bu içerik üçüncü taraf bir kaynağa aittir; arşiv ve nostalji amacıyla kaynak belirtilerek paylaşılmıştır. Hak sahibinin talebi hâlinde kaldırılır.

11 Haziran 1999

  1. [x − 2y/ln(x² + y²)]y′ = y + 2x/ln(x² + y²) denklemini çözünüz. y² = 4c(x + c) parabol ailesinin dik yörüngelerini bulunuz.
  2. {xᵐ, xⁿ} temel çözüm kümesine sahip ikinci mertebeden lineer homojen denklemi kurup tekil noktalarını belirleyiniz. Ayrıca y″ + 4y′ + y = e⁻²ˣ/(1 + x²) denklemini çözünüz.
  3. (1 − cos x)y″ − sin(x)y′ + y = 0 denkleminin düzenli tekil noktalarını, indis denklemini ve üstlerini bulunuz; Frobenius çözümü ve ikinci çözümün yapısını yazınız.
  4. x(1 − x)y″ + [p − (p + 2)x]y′ − py = 0 denklemini hipergeometrik fonksiyonlarla çözünüz. Elemanter fonksiyonlarla yazılabilir mi? p = 1 durumunu inceleyiniz.
  5. X′ = AX + f için A = [[0, −1, −1], [−1, 0, −1], [−1, −1, 0]], f = (e²ˣ, eˣ, 0)ᵀ veriliyor. Genel çözümü bulunuz.
  6. L{J₀(t)} = (1 + s²)⁻¹ᐟ² veriliyor. L{eᵇᵗJ₀(at)} ve ∫₀^∞ te⁻³ᵗJ₀(4t) dt ifadelerini hesaplayınız. ∫₀ᵗ F(τ)F(t − τ)dτ = sin t integral denklemini çözünüz. tY″ + (1 + 2t)Y′ + (5t + 1)Y = 0, Y(0) = 1, Y′(0) = −1 problemini Laplace yöntemiyle çözünüz.

25 Ağustos 2000: MAT201

  1. (2x + 1)y′ − 4e⁻ʸ + 2 = 0 için integrasyon çarpanı bularak genel çözümü çıkarınız.
  2. y⁽⁴⁾ − y = xeˣ + cos x denklemini çözünüz.
  3. x²y″ + (x² + 4x)y′ + 2(x + 1)y = 0 denkleminin x = 0 çevresinde bir Frobenius çözümünü bulunuz; elemanter biçimde yazınız. Mertebe düşürerek ikinci bağımsız çözümü elde ediniz.
  4. y″ + 4y = f(t), y(0) = 0, y′(0) = 1 problemini Laplace yöntemiyle çözünüz. f(t) = 1, 0 < t < 1; f(t) = 0, t > 1.
  5. X′ = [[2, −1], [3, −2]]X + (eᵗ, t)ᵀ sistemini çözünüz.

6 Ağustos 2001: İstanbul Teknik Üniversitesi MAT201

  1. y dx + (x − yx³) dy = 0 denklemini µ(xy) integrasyon çarpanıyla ve Bernoulli denklemi olarak çözünüz. Sonuçları karşılaştırınız.
  2. 4y⁽⁴⁾ + y = sin(x/2) + xe^(−x/2) denklemini çözünüz.
  3. xy″ − (x + 3)y′ + y = 0 denkleminin x = 0 çevresinde bir seri çözümünü bulunuz; diğer çözüm için mertebe düşürünüz.
  4. y‴(t) − y′(t) = f(t), y(0) = 1, y′(0) = −1, y″(0) = 0 problemini Laplace yöntemiyle çözünüz. Kaynak f(t) = eᵗ için t ≥ 2, f(t) = 0 için t > 2 yazıyor.
  5. y″ + 2y′ + 5y = e⁻ᵗ sin 2t, y(0) = 3, y′(0) = −1 problemini çözünüz.
  6. x₁′ = −x₂ + tan²t − 1, x₂′ = x₁ + tan t sisteminin genel çözümünü bulunuz.

Dördüncü ve beşinci sorular seçmelidir; toplam beş soru yanıtlanması isteniyor.

Not: 2001 sınavının dördüncü sorusunda t ≥ 2 ve t > 2 koşulları çakışıyor; t < 2 bölgesi tanımlanmamış. Parçalı fonksiyon kaynakta bu şekilde basılmıştır. Amaçlanan aralık doğrulanamadığından bir aralık seçilerek düzeltilmedi.
