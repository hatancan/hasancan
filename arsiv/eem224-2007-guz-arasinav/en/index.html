EEM224 Electromagnetics I: 2007 Fall Midterm Exam: Lossy Medium and Polarization

EEM224 – Elektromanyetik I · · 17.10.2026

This post was prepared from the 2007 fall semester Electromagnetics exam and solution pages; it was transcribed to text from photographed pages. The source refers to the old course code EEM323; in the archive it is classified under EEM224. Personal information was not transcribed. The photographs are kept in a private archive; there is no download file in this post.

Question 1: Field phasors

For a wave propagating in the +x direction in free space with its electric field along the +z direction, Ẽ=E₀â_z e^(−jk₀x) is given. The source solution writes the magnetic field as +(E₀/η₀)â_y e^(−jk₀x). The time expression of the electric field is E₀â_z cos(ωt−k₀x), and the power flux is shown in the +x direction.

Note: According to the relation H=(1/η₀)â_x×E, the direction of the magnetic field should be −y; the sign of H in the source solution is not consistent with the +x power direction it states.

Question 2: Good conductor approximation

μ=10μ₀, ε=72ε₀, σ=8 S/m; E=10e^(−αy)cos(π10⁷t−βy)â_z V/m. The result σ/(ωε)=400 supports the good conductor approximation.

The source gives α=β=4π, v_p=2.5×10⁶ m/s, λ=1/2 m, δ=1/(4π) m.

Note: In the calculation line, the factor μ=10μ₀ was omitted. With the given parameters, α≈β=4π√10, v_p=2.5×10⁶/√10 m/s, λ=1/(2√10) m, and δ=1/(4π√10) m.

Question 4: Polarization

The type of the curve traced over time by the following phasors and the direction of rotation are asked for:

  • (2â_x+j3â_z)e^(−jky): unequal orthogonal amplitudes and a 90° phase difference; elliptical.
  • H̃=(â_y−jâ_x)e^(−jkz): after the electric field is computed, circular with equal orthogonal amplitudes.
  • (2â_x+3â_z)e^(jky): components are in phase; linear.

The source writes "clockwise" for the first two plots. This definition must be read from the direction in which the plot is viewed; it should not be confused with the right-hand/left-hand definition relative to the propagation direction.

Note: The third page of the midterm is missing from the source folder; this post covers the available pages 1, 2, and 4.
