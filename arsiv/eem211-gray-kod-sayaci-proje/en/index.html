EEM211 Digital Logic Design: 3-Bit Gray Code Counter with D Flip-Flops (2012 Term Project)

EEM211 – Sayısal Mantık Tasarımı · 28.12.2012 · 17.10.2026

This post is a text transcription of a two-page project report for the EEM211 Digital Logic Design course's 2012 fall-term projects, on the topic "Design a 3-bit Gray code counter (D flip-flop)". The original was photographed with a phone on 28 December 2012 (the project topic is item 8 in the archived post Term Project Topics). The content was transcribed from the photographed pages into text; the photographs themselves have not been published.

Truth table

Since the characteristic equation of a D flip-flop is Q(t+1) = D, the truth table of the 3-bit Gray code counter is as follows (A is the most significant bit):

A(t) B(t) C(t)A(t+1) B(t+1) C(t+1)D1D2D3
000001001
001011011
011010010
010110110
110111111
111101101
101100100
100000000

State diagram

The counter cycles through its eight states in a ring; only one bit changes at each step:

000 → 001 → 011 → 010 → 110 → 111 → 101 → 100 → 000

Karnaugh maps and D inputs

BC = 00011110
D1, A = 00001
D1, A = 10111
D2, A = 00111
D2, A = 10001
D3, A = 01100
D3, A = 10011
  • D1 = BC' + AB + AC = B(C' + A) + AC
  • D2 = A'C + BC'
  • D3 = A'B' + AB

Note: The three expressions were checked one by one against all eight rows of the truth table; all of them give the correct next state.

Circuit

In the schematic on the second page, three D flip-flops (A, B, C) are driven by a common clock signal; the D inputs are generated by AND, OR, and inverter gates that implement the expressions above. The flip-flop outputs Q2, Q1, Q0 are each connected to one of three LEDs through a resistor; the Gray code sequence can be observed on the LEDs.
