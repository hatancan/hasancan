MAT222 Differential Equations: Study Questions and Sample Exams (Institution not specified)

MAT222 – Diferansiyel Denklemler · 17.11.2006 · 17.10.2026

This post brings together the 2006 handouts calismasorulari.pdf, sample_test_midterm.pdf and sample_test_final.pdf. The PDF dates are 17 November, 21 June and 18 July 2006, respectively. The documents do not name an author or institution; an affiliation with Ege University could not be verified. The three original PDFs, which contain no answer key, can be downloaded as a ZIP at the end of the post.

This content belongs to a third-party source; it is shared for archival and nostalgic purposes with attribution. It will be removed at the request of the rights holder.

Study questions: first order

  1. The first line in the source is printed as "ylnxxlnydx + dy = 0", with an ambiguous arrangement of products and exponents.
  2. dr = b(cos θ dr + r sin θ dθ).
  3. y′ = (3y − xy)/x, y(1) = 3e⁻¹.
  4. y(dx/dy) + 2x = 5y³.
  5. (x² + 1)y′ + 4xy = 3x.
  6. x dy + (xy + y − 1) dx. The source has no right-hand side of the equation.
  7. (x² + 3y²) dx − 2xy dy = 0, y(2) = 6.
  8. y³ dx = 2x³ dy − 2x²y dx, y(1) = 2.
  9. (x + √(xy))y′ + x − y = x⁻¹ᐟ²y³ᐟ², y(1) = 1.
  10. (x − y cos x) dx − sin x dy = 0.
  11. (2xy + eʸ) dx + (x² + xeʸ) dy = 0.
  12. (yeˣ + 2eˣ + y²) dx + (eˣ + 2xy) dy = 0, y(0) = 6.
  13. 2y² dx + (2x + 3xy) dy = 0.
  14. (x² + y² + x) dx + y dy = 0.
  15. cos(y)y′ + 2x − 2x sin y = 0.
  16. y²(dx/dy) + xy = 2y² + 1.

Note: The ambiguous typesetting in question 1 and the missing right-hand side in question 6 were not completed by guesswork.

Study questions: higher order and systems

17. (x³ − x²)y″ − (x³ + 2x² − 2x)y′ + (2x² + 2x − 2)y = 0. If f(x) = x² is a solution, find the other one.

18. (x² − 1)y″ − 2xy′ + 2y = 1. Using the solution f(x) = x of the homogeneous equation, find a particular solution.

19. y″ + y′/x − 4y/x² = 1 − 1/x³, x > 0. With the help of the homogeneous solution y₁ = x², find the complementary and particular solutions.

20. (D² + 1)y = 10e²ˣ, y(0) = y′(0) = 0.

21. y″ + 3y′ + 2y = eᵗ, y(0) = 0, y′(0) = 1. The x/t notation inconsistency in the source has been preserved.

22. (D − 1)²(D + 4)(D² + 4D + 5)y = 2eˣ + x − 3x² − xeˣ − 15 cos 2x. Find the form of the particular solution without computing its coefficients.

23. x²y″ − 3xy′ + 3y = (ln x)/x, x > 0.

24. (x + 1)(2x + 1)y″ + 2xy′ − 2y = 6x(x + 1), x > 0. Given the homogeneous solution f(x) = 1/(x + 1), find the general solution.

25. y⁽⁴⁾ + 2y‴ + y″ = x² + 4 + e⁻ˣ + e⁻ˣ sin x.

26. y″ − 2y′ + y = eˣ sin⁻¹x.

27. y″ + y = 1/(1 + sin x).

28. y″ + 3y′ + 2y = 1/(1 + eˣ).

29. x²y″ + xy′ + y = 1/[1 + sin(ln x)].

30. (1 − x)y″ + xy′ − y = 2(x − 1)²e⁻ˣ, 0 < x < 1. The homogeneous solutions eˣ and x are given. Find the complementary solution and the form of the particular solution.

31. Solve the system −5x₁ − 2x₂ + 2x₃ = 2; x₁ + 5x₂ − 3x₃ = 2; 5x₁ − 3x₂ + x₃ = 2 by Gaussian elimination, find the inverse of the coefficient matrix, and solve again using the inverse matrix.

32. For y″ − 4y = ln(x − 1), determine the interval on which the solution exists. Show that e²ˣ and e⁻²ˣ are linearly independent solutions of the homogeneous equation and write the complementary solution.

The handout reminds students that the exam also covers applications of differential equations and systems.

Sample midterm: model and first equations

  1. For d²y/ds² − yy⁽⁴⁾ + sy″ = 3s + 7 and y‴ + 5y′ + tan y = t² + cos t, determine the order, linearity, and the dependent and independent variables.
  2. Find the differential equation of the family of circles whose centers lie on the x-axis.
  3. A 1600 L tank initially contains 10 kg of salt. The inflow is 12 L/min at 0.5 kg/L; the outflow is at the same rate. Assuming perfect mixing, find the equation for the amount of salt, its solution, and the amount after 20 minutes.
  4. Solve the initial value problems u′ = (2t + sec²t)/(2u), u(0) = −5 and xy′ + y = y², y(1) = −1.
  5. y′ = tan(x + y − 3) − 1.
  6. [t cos(z/t) − z sin(z/t)]dt + t sin(z/t)dz = 0.
  7. [y/(x − 1)]dx + [ln(2x − 2) + 1/y]dy = 0.
  8. Find an integrating factor for (y³ + 2eˣy)dx + (eˣ + 3y²)dy = 0 and solve it.
  9. Solve the problems u′ − 2tu = 3t²eᵗ², u(0) = 5; eʸy′ + eʸ(ln x)/x = (ln x)/x, y(1) = 2; xz′ + xz + z = e⁻ˣ, x > 0.
  10. dz/dt + z sin t + z² sin 2t = 0.
  11. For x²y″ + 3xy′ + y = 0, x > 0, y₁ = 1/x is known. Find the second independent solution by reduction of order.
  12. Solve y′ = x² + y², y(0) = 1 on [0,1] by Euler's method with h = 0.2.

Sample midterm: 13–14

Question 13 asks for the general solutions of the following equations:

  • y⁽⁴⁾ − 7y‴ + y″ − 7y′ = e⁻²ˣ.
  • x²y″ + xy′ − 4y = x² ln x.
  • y⁽⁴⁾ + 2y″ + y = xeˣ.
  • y″ − 4y′ + 4y = e²ˣ ln x/x.

The systems in question 14:

  • x′ = −2x + 2z, y′ = 2x − 4y, z′ = 4x − 2y.
  • x₁′ = −2x₁ + x₂ + 2e⁻ᵗ, x₂′ = x₁ − 2x₂ + 3t; x₁(0) = 1, x₂(0) = −1.

Sample final

  1. Find the differential equation of the family y = Ae²ˣ + Bx.
  2. An 800 L tank initially contains 5 kg of salt. The inflow is 6 L/min with concentration 0.5 kg/L, and the outflow is at the same rate. Find the equation and its solution, as well as the amount of salt after 10 minutes.
  3. dx/dt = x/5 − x²/25, x(0) = 1.
  4. y′ − 4y tan x = [sin x/(2cos³x)]y¹ᐟ².
  5. y′ = tan(x + y − 3) − 1.
  6. Find an integrating factor for (3xeʸ + 2y)dx + (x²eʸ + x)dy = 0.
  7. [y/(x − 1)]dx + [ln(2x − 2) + 1/y]dy = 0.
  8. Find a power series solution of (1 + 2x²)y″ + xy′ + 2y = 0.
  9. Find a series solution about x = 0 for 2x²y″ + 3xy′ − (x² + 1)y = 0.
  10. z″ − 4z′ + 4z = e²ᵗ ln t/t.
  11. For x²y″ + 3xy′ + y = 0, x > 0, find the second solution using y₁ = 1/x.
  12. Solve y′ = 2x² + 3y², y(0) = 1 on [0,2] by Euler's method with h = 0.4.
  13. y‴ − 4y″ + 5y′ − 2y = 4 cos x + sin x.
  14. x₁′ = x₁ + √3x₂ + eᵗ, x₂′ = √3x₁ − x₂ + √3e⁻ᵗ; x₁(0) = 1, x₂(0) = −1.
  15. Find the inverse Laplace transform of F(s) = (3s² − 2s + 5)/[(s − 2)(s² + 9)].
  16. Find the Laplace transform of f(t) = te⁻ᵗ cos t.
  17. Solve the following three initial value problems by the Laplace method.

Parts of the last question:

  • y″ + 2y = 4t² + 12; y(0) = 4, y′(0) = 0.
  • y″ + y = e⁻²ᵗ sin t; y(0) = y′(0) = 0.
  • y″ − y′ − 6y = r(t); y(0) = 1/50, y′(0) = −7/50. r(t) = sin t, 0 < t < 3π; r(t) = 0, t > 3π.

Quick computational checks

In the mixing problems, the balance of inflow minus outflow is used for the amount of salt m. In the midterm, m′ = 6 − 0.0075m and m(t) = 800 − 790e⁻⁰·⁰⁰⁷⁵ᵗ; in the final, m′ = 3 − 0.0075m and m(t) = 400 − 395e⁻⁰·⁰⁰⁷⁵ᵗ. The second independent Euler solution is ln x/x. These results are not the handout's answers but checks made during the transcription.
