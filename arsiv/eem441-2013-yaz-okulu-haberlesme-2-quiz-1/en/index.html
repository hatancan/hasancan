EEM441 Communications I: 2013 Summer School EEM 442 Communications II Quiz I (July 24, 2013) and Solutions

EEM441 – Haberleşme I · 24.07.2013 · 14.11.2026

This document belongs to the EEM 442 Communications II course; it is published here because it was kept in the EEM 441 folder. It is a text transcription of the questions and handwritten solutions of Quiz I (July 24, 2013, duration 1 hour) of the Başkent University EEM 442 Communications II summer school. The exam paper and solutions were transcribed from photographed pages; the photographs are not published. For this reason, there is no downloadable original file. Personal information (student number, name) has been removed.

Questions

  1. In a digital communication system, a pulse-modulated wave is generated by uniformly sampling the signal x(t) = cos(2πt/T_m) at times t = kT_s, where T_s = T_m/3. Sketch the pulse-modulated signal x_p(t) a) for PDM with μ = 0.8 and τ₀ = 0.4 T_s, b) for PPM with t_d = 0.5 T_s and t₀ = τ = 0.2 T_s.
  2. A voice signal in the frequency range 300–3300 Hz is sampled at 8000 samples/s. These samples can be sent directly as M-ary PAM, or each sample can first be converted to PCM and sent as binary PCM signals. a) Calculate the minimum system bandwidth required to detect the PAM signals without ISI using a filter with roll-off α = 1. b) Find the minimum bandwidth required to detect binary PCM signals quantized to eight levels, with the same roll-off characteristic. c) To have the same BER in both systems, the binary PCM system uses amplitude levels of ±1; the 8 levels in PAM are 1, 3, 5, 7, 9, 11, 13, 15, mapped to 000…111. Compare the two systems in terms of transmission bandwidth and output power.

The formula sheet provided with the exam includes: B_T = (1/2T_s)(1 + α) = (R_s/2)(1 + α); SNR₀ = 3×2^(2R)/α, α = peak power/average power; M-PAM symbol error probability P_E(M) = [2(M − 1)/M] Q(√(6 E_s,av /((M² − 1)N₀))); PAM x_p(t) = Σ A₀[1 + μ x(kT_s)] p(t − kT_s); PPM t_k = kT_s + t_d + t₀ x(kT_s); PDM τ_k = τ₀[1 + μ x(kT_s)]; for M-ary PCM L = M^R, SNR_th ≈ (6B_T/W)(M² − 1); the Q function and erfc relations, and the PDM/PPM generation diagram (sawtooth generator, comparator, monostable).

Solution 1

x(kT_s) = cos(2πk/3): 1 for k = 0, −0.5 for k = 1, −0.5 for k = 2, 1 for k = 3.

a) PDM: τ_k = τ₀[1 + μ x(kT_s)] = 0.4 T_s [1 + 0.8 cos(2πk/3)]. k = 0: 0.4 T_s (1 + 0.8) = 0.72 T_s; k = 1: 0.4 T_s (1 − 0.4) = 0.24 T_s; k = 2: 0.24 T_s; k = 3: 0.72 T_s. The pulses start at times kT_s, have constant amplitude, and have widths 0.72 T_s, 0.24 T_s, 0.24 T_s, 0.72 T_s (time axis in units of T_s: 0–0.72; 1–1.24; 2–2.24; 3–3.72).

b) PPM: t_k = kT_s + t_d + t₀ x(kT_s) = T_s[k + 0.5 + 0.2 cos(2πk/3)] (t_d/T_s = 0.5, t₀/T_s = 0.2). k = 0: 0.7 T_s; k = 1: 1.4 T_s; k = 2: 2.4 T_s; k = 3: 3.7 T_s. Each pulse has a width of 0.2 T_s (0.7–0.9; 1.4–1.6; 2.4–2.6; 3.7–3.9).

Solution 2

T_s = 1/f_s = 1/8000 s = 125 µs.

a) PAM: Nyquist bandwidth W = 1/(2T_s) = R_s/2 = f_s/2 = 4 kHz. For roll-off α = 1, B = W(1 + α) = 8 kHz.

b) Eight-level quantized binary PCM: each sample is log₂8 = 3 bits; symbol rate R_s = 3 f_s = 24 kbit/s. B = (R_s/2)(1 + α) = R_s = 24 kHz.

c) Binary PCM: levels are ±1; average energy E_av = 3[(±1)² T_s/3] = T_s (three bits, each of duration T_s/3; T_s = T_b log₂M, where log₂M = 3). 8-ary PAM: levels 1, 3, 5, 7, 9, 11, 13, 15; E_av = (T_s/8)(1² + 3² + 5² + 7² + 9² + 11² + 13² + 15²) = (T_s/8)(1 + 9 + 25 + 49 + 81 + 121 + 169 + 225) = 85 T_s. The average energy increase of 8-ary PAM relative to binary PCM is 85 T_s / T_s = 85 (19.3 dB); the bandwidth reduction is 8 kHz / 24 kHz = 1/3.

Alternatively, if the levels are taken as 0…7: E_av = (T_s/8)(0² + 1² + … + 7²) = (T_s/8)(140) = 17.5 T_s; the power increase is 17.5 (12.43 dB).

Note: In the handwritten solution, the parenthetical labels in parts a) and b) ("binary PCM", "M-ary PAM") are mixed up; according to the question text, 8 kHz belongs to PAM and 24 kHz to binary PCM. Similarly, the expression "4000 kHz" should be 4 kHz.
