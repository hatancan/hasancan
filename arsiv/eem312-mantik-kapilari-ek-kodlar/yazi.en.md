baslik: EEM312 Digital Electronics: Additional SPICE Netlists for Logic Gates, NAND, NOR and XOR
ozet: Additional archived SPICE source files for two- and three-input CMOS gates, XOR trials with fixed inputs, and delay studies; with notes on connections and loading.
---

This post collects additional logic gate netlists prepared by classmates for the Başkent University **EEM312 Digital Electronics** laboratory. Student names and personal folder names have been removed from the archive copies of the 2005–2011 work. Files were selected that differ from the code in the earlier [logic gate reports](/arsiv/eem312-rapor-mantik-kapisi-tasarimi/) in connection, sizing, or analysis settings. The cleaned sources can be downloaded as a ZIP at the end of the post; the code was not run.

## Connections and issues seen in the source

In the three-input NAND network, three PMOS transistors are connected in parallel and three NMOS transistors in series; the NOR network is the reverse. The 200, 400 and 800 ns periods of the input pulses produce the different logic combinations. The transient commands plot the output as a function of time.

*Note: In `grup-a/b.cir`, the NMOS chain ends at node 9, which is not connected to ground. The transistors corresponding to the third pulse source are also missing. The file should not be regarded as a completed three-input NAND; the source was not modified.*

*Note: In `grup-a/a.cir`, `vin3` directly drives node 5, the observed output node. In this case the output will not show only the logic function of the transistor network.*

*Note: Despite its name, `giris-denemeleri/3-NOR.cir` has two inputs; in addition, the waveforms of the two pulse sources are identical. In `grup-c/Nand.cir`, `c1 5 0 1fF` is connected to input node 5 rather than output node 2.*

## Model and file layout

The files use Level 2 MOSN/MOSP models. Generally L = 1.2 µm, NMOS W = 1.8 µm and PMOS W = 5.4 µm; the sizes have been changed in some gates. The model lines are preserved in every file. Files/folders carrying personal names have been replaced with neutral names.

File: `grup-a/a.cir`.

```spice
* Arsiv devre kaydi

.MODEL MOSN NMOS LEVEL=2 LD=0.15U TOX=200.0E-10 
+ NSUB=5.36726E+15 VTO=0.743469 KP=8.00059E-05 GAMMA=0.543 
+ PHI=0.6 U0=655.881 UEXP=0.157282 UCRIT=31443.8 
+ DELTA=2.39824 VMAX=55260.9 XJ=0.25U LAMBDA=0.0367072 
+ NFS=1E+12 NEFF=1.001 NSS=1E+11 TPG=1.0 RSH=70.00 
+ CGDO=4.3E-10 CGSO=4.3E-10 CJ=0.0003 MJ=0.6585 
+ CJSW=8.0E-10 MJSW=0.2402 PB=0.58 

.MODEL MOSP PMOS LEVEL=2 LD=0.15U TOX=200.0E-10 
+ NSUB=4.3318E+15 VTO=-0.738861 KP=2.70E-05 GAMMA=0.58 
+ PHI=0.6 U0=261.977 UEXP=0.323932 UCRIT=65719.8 
+ DELTA=1.79192 VMAX=25694 XJ=0.25U LAMBDA=0.0612279 
+ NFS=1E+12 NEFF=1.001 NSS=1E+11 TPG=-1.0 RSH=120.6 
+ CGDO=4.3E-10 CGSO=4.3E-10 CJ=0.0005 MJ=0.5052 
+ CJSW=1.349E-10 MJSW=0.2417 PB=0.64

*  D G S B

M1 1 2 3 1 MOSP W=3.6u L=1.2u
M2 2 4 5 2 MOSP W=3.6u L=1.2u
M3 5 2 4 5 MOSP W=3.6u L=1.2u

M4 3 2 0 0 MOSN W=1.8u L=1.2u
M5 5 4 3 0 MOSN W=1.8u L=1.2u
M6 4 3 5 5 MOSN W=1.8u L=1.2u

vdd 1 0 5V
*va 2 0 5V
*vb 4 0 5V

Vin1 2 0 pulse(0V 5V 0 0ns 0ns 100ns 200ns)
Vin2 4 0 pulse(0V 5V 0 0ns 0ns 200ns 400ns)

.control

plot v(2) 
plot v(4)
plot v(5)
 
.endc
.end
```
