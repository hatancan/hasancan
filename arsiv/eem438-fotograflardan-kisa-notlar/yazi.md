Ders arşivindeki anonim notlar, fotoğraflanmış sayfalardan metne aktarıldı. Fotoğraflar özel arşivde saklanır; bu yazıda indirme dosyası yoktur. Belge üzerinde tarih yoksa kaynak dosyanın tarih kaydı kullanılmıştır.

## Kablosuz ve mobil ağ kısaltmaları

| Kısaltma | Kaynaktaki açılım/açıklama |
|---|---|
| AP | Access Point |
| Wi-Fi | Wireless Fidelity |
| HSDPA | High-Speed Downlink Packet Access |
| UMTS | Universal Mobile Telecommunications System |
| WCDMA | Wideband Code Division Multiple Access |
| GSM | Global System for Mobile Communications |
| WiMAX | Worldwide Interoperability for Microwave Access |
| SNR | Signal-to-Noise Ratio |
| BER | Bit Error Rate |
| CDMA | Code Division Multiple Access |
| BSS | Basic Service Set |
| SSID | Service Set Identifier |
| CSMA | Hattı dinleme |
| DIFS | Distributed Interframe Space |
| SIFS | Short Interface Space; rastgele bekleme süresi [kaynakta] |
| RTS | Request to Send |
| BS | Base Station |
| CTS | Clear to Send |
| FDMA | Frequency Division Multiple Access |
| TDMA | Time Division Multiple Access |
| MSC | Mobile Switching Center |
| BSC | Base Station Controller |
| SGSN | Serving GPRS Support Node |
| GGSN | Gateway GPRS Support Node |

*Not: SIFS = Short Interframe Space’tir ve rastgele backoff değildir. CSMA = Carrier Sense Multiple Access. “Wireless Fidelity” fotoğraftaki ifadedir; Wi-Fi adının teknik açılımı gibi okunmamalıdır.*

## Doğrudan yönlendirme

Correspondent, mobilin nerede olduğunu home agent’a sorar; geçici adres bilgisi alındıktan sonra trafik ziyaret edilen ağdaki foreign agent üzerinden mobile ulaşır. Mobil başka ağa geçerse ilk foreign agent üzerinden yeni foreign agent’a iletim yapılmasını anlatan çizimde ilk aracı “anchor foreign agent” olarak adlandırılmıştır. Aynı sayfa vize notları PDF’sinde de bulunduğundan çizim tekrar yayınlanmadı.
