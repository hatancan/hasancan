## Wireless and mobile network abbreviations

| Abbreviation | Expansion/explanation in the source |
|---|---|
| AP | Access Point |
| Wi-Fi | Wireless Fidelity |
| HSDPA | High-Speed Downlink Packet Access |
| UMTS | Universal Mobile Telecommunications System |
| WCDMA | Wideband Code Division Multiple Access |
| GSM | Global System for Mobile Communications |
| WiMAX | Worldwide Interoperability for Microwave Access |
| SNR | Signal-to-Noise Ratio |
| BER | Bit Error Rate |
| CDMA | Code Division Multiple Access |
| BSS | Basic Service Set |
| SSID | Service Set Identifier |
| CSMA | Carrier sensing (listening to the line) |
| DIFS | Distributed Interframe Space |
| SIFS | Short Interface Space; random waiting time [in the source] |
| RTS | Request to Send |
| BS | Base Station |
| CTS | Clear to Send |
| FDMA | Frequency Division Multiple Access |
| TDMA | Time Division Multiple Access |
| MSC | Mobile Switching Center |
| BSC | Base Station Controller |
| SGSN | Serving GPRS Support Node |
| GGSN | Gateway GPRS Support Node |

*Note: SIFS stands for Short Interframe Space and is not a random backoff. CSMA = Carrier Sense Multiple Access. "Wireless Fidelity" is the wording in the photograph; it should not be read as the technical expansion of the name Wi-Fi.*

## Direct routing

The correspondent asks the home agent where the mobile is; once the care-of address is obtained, traffic reaches the mobile through the foreign agent in the visited network. In the drawing that describes forwarding from the first foreign agent to the new foreign agent when the mobile moves to another network, the first intermediary is called the "anchor foreign agent." Since the same page is also in the midterm notes PDF, the drawing was not published again.
