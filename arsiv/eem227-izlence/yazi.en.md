This post is the syllabus for the **EEM227 Data Structures** course in the Electrical and Electronics Engineering Department at Başkent University. It was prepared by Atilla Özgür and dated September 22, 2014. The course was taught in Java; the other EEM227 posts in the archive consist of code examples from this course. The original PDF of the syllabus can be downloaded at the end of the post.

## Course objectives

- An introduction to the data structures most commonly encountered in software programming
- When and how to use data structures within a programming language
- Which data structure is more suitable for solving which problems
- The core logic behind data structures
- Writing the code for data structures

## Grading

| Component | Percentage |
|---|---|
| Quiz | 15% |
| Midterm exam | 35% |
| Final exam | 45% |
| Attendance | 5% |
| Total | 100% |

## Course content and exams

All course content was published through the instructor's WordPress site and YouTube channel; students were responsible for the videos on YouTube and the lecture notes on WordPress. Twitter was also used for announcements, but the main source was the WordPress site.

- atiozgur.wordpress.com/verilen-dersler/baskent-eem-227/
- youtube.com/user/ati1ozgur

The exams were **open-notes**: the lecture notes on the site and the printouts of previously given labs could be printed and used in the exam, and you could add your own notes on the back of these printouts. No other books or printouts were allowed.

## Topics

**Weeks 1–2: Software development environment and Java review**

- JDK installation, BlueJ IDE (integrated development environment), Eclipse installation
- Class, main method
- Primitive data types and reference data types
- Control structures and loop structures
- References in Java, call by reference and call by value
- Constructor

**Week 3: Basic data structures**

- Arrays and the array resize problem
- Array lists and their use in Java
- Linked lists and their use in Java
- Doubly linked lists

**Week 4: Java supporting topics**

- Generics
- Iterators

**Week 5: Design principles and analysis techniques**

- Data structures and algorithms
- Operating system: the concepts of stack and heap
- Object-oriented design principles
- Running time and a quick review of mathematics
- Algorithm analysis, asymptotic notation (Big-Oh), and asymptotic analysis

**Weeks 6–7: Stack, queue, list**

- Stack and its use in Java
- Queue and its use in Java
- Double-ended queue (deque) and its use in Java

**Week 8: Dictionaries and trees**

- The dictionary abstract data type
- Binary search trees, AVL trees
- Hash tables
- Recursion

**Week 9: Sets**

- Sets and their use in Java

**Weeks 10–12: Sorting and selection**

- Bubble sort, quick sort, merge sort, radix sort
- Complexity of sorting
- Selection

**Weeks 13–14: Sequences**

- Ranked sequences, positional sequences, general sequences
- Priority queues (if time permits): the priority queue abstract data type, priority queue as a sequence, heaps

**Topics removed:** graph algorithms, binary decision trees, dynamic programming.
